## §3 BUILD/DEVICE FACTS (each learned the hard way)

- Release build (normal): `npx expo run:ios --device --configuration
  Release`. Debug build (only for __DEV__ panels): same without the
  Release flag; needs the terminal window left open (Metro) + phone on
  the SAME WIFI (5G = red box "TurboModuleManager timed out").
- First-ever debug build hit a linker error (Sealable): fix is FULL pods
  re-fetch — `cd ios && rm -rf Pods build && pod install` (rm build
  alone is not enough; RN prebuilt core is per-configuration).
- New phone (e.g. Renee's): register once via `xcodebuild
  -allowProvisioningUpdates -allowProvisioningDeviceRegistration` with
  the device id, plus Developer Mode + trust on the phone.
- The 2-minute notification proof panel is __DEV__-only: ABSENT in
  Release, which looks identical to broken. Know this before debugging.
