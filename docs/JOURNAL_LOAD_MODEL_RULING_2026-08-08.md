## THE MODEL — three layers, one system, all derived from stored facts

1. TWO NATIVE STREAMS. Strength load = TONNAGE (sets x reps x kg from
   assume-prescribed completion — the app already knows it).
   Conditioning load = sRPE AU (athlete difficulty rating x session
   minutes — both already stored). Raw units never cross streams.
2. COMBINE IN RATIO SPACE ONLY. Each stream vs ITS OWN rolling 4-week
   normal; the unitless ratios combine into ONE headline continuum with
   a Sam-signed sweet-spot band. The card may show the honest split
   beneath ("lifting well up, running about normal").
3. REGION LAYER. The same per-session load distributes across the
   Sam-signed muscle data (exercise muscleGroups; conditioning muscle
   metadata per quality). Per-region weekly load vs that region's own
   normal -> OBSERVATION LINES ONLY ("Hamstrings had their biggest week
   in a month — heavy lower Tuesday, speed Friday"). Region keying
   matches niggle history.

FALLBACK RUNG: any session with no rating scores by the signed 2/1/0
day weights — the number never has a hole and never invents precision.

FEATURE ADDITION APPROVED (Sam: "if we have to add a feature we can"):
the effort tap extends to strength sessions, riding the ruled "felt
different" tap surface — one tap, no per-set anything.

## LAWS THAT BIND THE BUILD

- ATHLETE NEVER SEES RAW AU. Calm signed language + the band; no scores
  out of 100 (avoid-list holds).
- OBSERVATION, NEVER DIAGNOSIS. "Ran hot" beside facts; no injury-risk
  claims anywhere.
- JOURNAL STAYS A READING SURFACE. Region stress influencing program
  PLACEMENT (e.g. spacing heavy-lower away from speed days) is a NAMED
  PARKED UNIT for the engine, through existing owners — not this build.
- CONSTANTS ARE SAM'S: stream weighting for the headline (default
  proposal 50/50), sweet-spot band edges (literature reference
  ~0.8-1.3 of normal), tonnage-modulated-by-effort yes/no, and the
  region-normal window — ONE signing batch when the load slice opens.

Sequencing unchanged: note-input slice first, then the load slice
builds this model.
