# The optional placement sheet — for Sam's signing

**Your law, 2026-07-30:** the generator may place optional work ONLY under a
Sam-authored placement rule, with Sam-authored composition, rendered visibly
optional, binnable in one tap, and never counted toward compliance, load or rest.

**Nothing places without a signed rule.** This sheet is every optional placement
the app makes today, written out as a RULE — trigger, day preference, cap,
composition source — so you can sign, amend or kill each one. Same format as the
gunshow candidates.

**Read this first:** these are not proposals for new behaviour. Every row is
something the app already does, traced to what authorises it. Where the authority
is a Bible line, it is quoted. Where there ISN'T one, the row says so plainly —
those are the rows that matter most.

## §3 — Mobility regions: PROPOSED, needs signing

Composing a mobility session "across lower / hips / midline / upper" needs to
know which region each of your twenty mobility exercises is. **The pool does not
carry that**, so this table is mine and is not trusted until you sign it.

| Region | Exercises |
|---|---|
| **lower** | Deep Squat Hold, Toe Stretch, Calf Stretch, ATG Split Squat, Elephant Walks |
| **hips** | Hip 90/90 Stretch, World's Greatest Stretch, Couch Stretch, Pigeon Stretch, Adductor Rockback, Butterfly Stretch, Pissing Dog Against Wall |
| **midline** | Cat-Cow, QL Back Extension, Jefferson Curl |
| **upper** | Open Book Thoracic Rotation, Chest / Pec Stretch (Doorway), Lat Stretch, Dead Hang, Dumbbell Pullovers |

Twenty exercises, four regions, every one assigned. Where your authored
`contraindications` name a body area they were the strongest evidence available
— `couch-stretch` carries `['knee','hip']` and stretches a hip flexor, so hips.
Nothing was derived automatically, because a derivation would hide that this is a
judgement you have not made.

**Also proposed:** a composed session targets **6** movements — the middle of
your 5-8 window, which you ruled, where the 6 you did not. It shrinks below six
when equipment or injury filtering leaves a region short, and never pads.
