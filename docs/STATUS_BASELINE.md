## What fought me, worth the next seat's time

1. **`[ProgramGen] AI omitted weekly plan days` is not a per-week planner
   receipt.** With the AI severed it fires on every build, and it fires **per
   repair candidate** — 28 to 184 warnings for 4 microcycles. A first pass read
   the planner's request out of it and reported 16 worlds dropping planned days.
   **That number was wrong; it is retracted in the baseline doc rather than
   quietly dropped.** §1.4 now uses the athlete's own answer as the denominator.

2. **The projection renames rows.** `Pallof Press → Band Pallof Press`,
   `Romanian Deadlift → RDLs`, `Face Pulls → Face Pull`. Measuring equipment
   legality against the STORED name gives 352 illegal rows; against the SHOWN
   name it gives 538. **Both were kept; the shown-name number is the athlete's.**
   A single-column answer here would have understated the defect by 186 rows.

3. **A pool `group` narrows the eligible set, and getting that filter wrong moved
   the variety ratio from 0.77 to 0.90.** A first pass required grouped siblings
   to have no group and produced four classes with an eligible set of ZERO while
   rows were plainly being delivered into them.

4. **`completeOnboarding()` refuses `teamTrainingDays: []`** for pre-season and
   in-season (`onboardingSteps.ts:127`). The 180-world sweep builds 90 `noclub`
   pre/in-season worlds the onboarding door would not create. Recorded as
